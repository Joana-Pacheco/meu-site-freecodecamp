# CatPhotoApp – freeCodeCamp

Projeto desenvolvido durante os estudos de **HTML básico** na plataforma **freeCodeCamp**.

## 🔍 Sobre o projeto
O **CatPhotoApp** é um site estático simples, criado para praticar a estruturação de páginas web utilizando apenas HTML.  
O projeto explora títulos, parágrafos, links, imagens, listas e formulários, seguindo boas práticas iniciais de marcação.

## 🛠️ Tecnologias utilizadas
- HTML5

## 🎯 Conceitos praticados
- Estrutura básica de um documento HTML
- Uso de tags semânticas (`main`, `section`, `footer`)
- Inserção de imagens e links
- Listas ordenadas e não ordenadas
- Formulários com inputs, labels, radio buttons e checkboxes
- Boas práticas de organização do código
